# Деплой — пошагово

Сайт статический: HTML, CSS, JS и картинки. Никакого сервера, базы и сборки.
Значит, подойдёт любой бесплатный хостинг.

---

## Шаг 1. Домен

Сначала домен, потом деплой — так превью в чатах заработает сразу.

Где брать в Кыргызстане:
- **`.kg`** — через регистраторов домена (`cctld.kg` и партнёры), нужны документы
- **`.com` / `.site` / `.fun`** — Namecheap, Porkbun: карта и пять минут
- Не хочешь платить — **пропусти этот шаг**, Netlify и Vercel дают
  бесплатный адрес вида `vote4musya.netlify.app`. Для школьных выборов этого
  более чем хватает.

Хорошие варианты имени: `vote4musya`, `musya67`, `za-musyu`.

## Шаг 2. Залить сайт

### Netlify — проще всего, без терминала

1. Открой [app.netlify.com/drop](https://app.netlify.com/drop)
2. **Перетащи туда папку `vote4musya`** целиком
3. Готово — сайт работает, ссылку дают сразу

Домен подключается в `Site settings → Domain management → Add custom domain`.

### Vercel

1. `vercel.com` → Add New → Project
2. Перетащи папку или подключи GitHub
3. Домен — в `Settings → Domains`

### GitHub Pages

```sh
cd vote4musya
git init
git add .
git commit -m "Агитационный сайт"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/vote4musya.git
git push -u origin main
```

Потом в репозитории: `Settings → Pages → Source: main → /(root)`.
Адрес будет `твой-ник.github.io/vote4musya`.

**Что НЕ поедет:** папки `.impeccable/`, `.playwright-mcp/` и `img/team/raw/`
уже прописаны в `.gitignore`. Если заливаешь перетаскиванием — можешь удалить
их руками, это 700 КБ лишнего веса. Сам сайт весит около 2 МБ.

## Шаг 3. После покупки домена — обязательно

Открой `index.html` и замени две строки в самом верху:

```html
<meta property="og:url" content="https://ТВОЙ-ДОМЕН/">
<meta property="og:image" content="https://ТВОЙ-ДОМЕН/img/og.jpg">
```

**Это не мелочь.** Без абсолютных адресов Telegram и WhatsApp не покажут
превью — ссылка будет голой, без картинки и заголовка. А сайт рассчитан
на то, что его кидают в чат.

Проверить превью после деплоя:
- Telegram: напиши `@WebpageBot`, отправь ему ссылку
- Общая проверка: `opengraph.xyz`

Если превью не обновилось — Telegram кеширует, тот же `@WebpageBot` умеет
сбрасывать кеш.

## Шаг 4. Проверить на телефоне

Открой сайт с телефона и пройди по списку:

- [ ] Шрифты подгрузились (заголовки округлые, не системные)
- [ ] Все шесть фото партии на месте
- [ ] Форма предложений загрузилась и поле появилось
- [ ] Отправь тестовое предложение → приходит код
- [ ] Ссылка «Посмотреть статус» открывается
- [ ] Ссылку кинул сам себе в чат → превью с картинкой

## Если что-то сломалось

**Шрифты системные, всё выглядит не так**
Папка `fonts/` не залилась. Проверь, что она на хостинге вместе с `fonts.css`.

**Фото партии не видно**
Папка `img/team/` не залилась. Страница это переживёт — покажет пунктирные
слоты, — но лучше долить файлы.

**Форма пишет «Не получилось загрузить анкету»**
Проверь в браузере: `studyfreeforum.com/api/forms/public/form_1789541783872`.
Если сервер отвечает, а на сайте ошибка — скорее всего CORS с нового домена,
напиши администратору кабинета.

**Превью в чате без картинки**
Не сделан Шаг 3.

---

## Что поменять потом, из кабинета

Анкету можно править в кабинете, не трогая сайт: добавить поля, сделать
что-то обязательным, поменять описание. Страница подхватит сама — она
спрашивает структуру у сервера при каждой загрузке.

Код сайта нужно трогать только если решишь сменить саму анкету —
это одна строка `var FORM` в `app.js`.

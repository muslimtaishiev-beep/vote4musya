# Муся — президент школы

Агитационный сайт кандидата в президенты школы. Одна страница, без сборки:
открывается двойным кликом по `index.html` или заливается на любой хостинг
как есть (GitHub Pages, Netlify, Vercel, флешка).

## Как запустить локально

```sh
cd vote4musya
python3 -m http.server 4321
# открыть http://127.0.0.1:4321
```

Сервер нужен только для того, чтобы браузер отдал шрифты: файл по `file://`
тоже откроется, но шрифты могут не подхватиться.

## Что где лежит

```
index.html   страница целиком
style.css    весь дизайн; переменные мира — в самом верху, в :root
app.js       появление блоков, обводка кругов, форма, «поделиться»
fonts/       4 шрифта, свои, не с чужого CDN (кириллица + латиница)
img/         8 пиксель-спрайтов + PROVENANCE.md + sprites.py
```

## Фото партии

**Уже стоят.** Шесть портретов обрезаны и лежат в `img/team/`.
Исходники сохранены в `img/team/raw/` — если захочешь перекадрировать,
просто запусти `sh crop-team.sh` ещё раз.

Имена участников **намеренно не подписаны** — ты просил пока оставить
только своё. Когда решишь добавить, найди в `index.html` строку
`<p class="team__r team__r--only">партия 67</p>` у нужного человека и
поставь перед ней:

```html
<p class="team__n">Имя</p>
```

### Если захочешь добавить фото с постером

Положи его в `img/team/raw/poster.jpg`, запусти `sh crop-team.sh`, и в
`index.html` верни блок `<figure class="poster">` перед закрытием секции
команды. Сейчас его нет, и страница это корректно переживает — блок
удаляет себя сам, если файла не существует.

## Что ещё нужно заменить перед публикацией

Эти вещи намеренно **не выдуманы** — их нужно вписать самому:

- [ ] **Дата выборов** — сейчас её на странице нет
- [ ] **Контакты** (Telegram / Instagram) — в подвале
- [ ] ~~**Блок «кто я»**~~ — готов, написан твоими словами: кондитер,
      угарный челик, топлю за своих
- [x] ~~**Форма идей**~~ — подключена к кабинету «Академии будущих лидеров».
- [ ] **Анонимная поддержка** — кнопка «Как это будет работать» пока ведёт вниз
      по странице. Поставь туда настоящую ссылку на канал.

## Как поменять цвета и размеры

Всё в `:root` в начале `style.css`:

```css
--paper:  #FAF7EE;   /* бумага */
--blue:   #1B3FD8;   /* основная паста */
--red:    #E32B1E;   /* обводка имени */
--green:  #0E6F3C;   /* статус «идёт сейчас» */
--cell:   26px;      /* размер клетки */
```

## Как добавить пункт программы

Скопируй любой `<li class="plank rise">` в `index.html` и поменяй текст.
Статус — это класс на `<span class="status">`:

- `status--now` — сплошная рамка, закрашенный кружок («идёт сейчас»)
- `status--plan` — пунктирная рамка, пустой кружок («план»)

Статус различается **формой**, а не только цветом: страница остаётся читаемой
на чёрно-белой печати и для тех, кто не различает цвета.

## Доступность

- контраст всех текстов ≥ 4.5:1
- у каждого элемента видимое кольцо фокуса для клавиатуры
- при `prefers-reduced-motion: reduce` анимации выключаются полностью,
  и весь контент виден сразу — ничего не прячется за анимацией


## Форма предложений — как это работает

Заявки уходят в кабинет организации `org_future_leaders` на
`studyfreeforum.com`, в анкету **«Предложения по улучшению школы»**
(`form_1789541783872`). Анкета анонимная: имени она не спрашивает.

Человек отправляет предложение → получает код вида `EWJQECCBK5` → может
посмотреть статус по ссылке `studyfreeforum.com/track/{код}`.

### Важно: поля не вшиты в код

Страница **спрашивает у сервера**, какие поля рисовать, и строит форму по
ответу. Если организатор поменяет анкету в кабинете — добавит поле, сделает
что-то обязательным, поменяет описание — сайт подхватит это сам, менять код
не нужно.

Поэтому не переписывай поля руками в `index.html`: там стоит пустой
контейнер `<div id="ideaFields">`, его заполняет `app.js`.

### Как поменять анкету

Одна строка в `app.js`:

```js
var FORM = 'form_1789541783872';
```

Другие анкеты организации:

| Анкета | formId |
|---|---|
| Предложения по улучшению школы | `form_1789541783872` |
| Идеи и предложения для парламента | `form_1789491208354` |
| Поступление в АБЛ 1–11 класс ОРТО-САЙ | `form_1788342891846` |
| ХАКАТОН (режим билета) | `form_1788613220215` |
| Анкета для родителей АБЛ Орто-Сай | `form_1789023839447` |

### Что уже предусмотрено

- **Анкета закрыта** (код 410) — форма не рисуется, показывается текст с сервера
- **Сервер недоступен** — честное сообщение, а не зависшая форма
- **Двойное нажатие** — кнопка блокируется на время отправки (сервер от этого не защищает)
- **Обязательные поля** — проверяются до отправки
- **Фотографии** — сжимаются в браузере до 400 КБ, принимаются только JPG и PNG
- **Все типы полей** — text, textarea, number, date, select, checkbox, file

## Витрина предложений — чего ждём

Сайт умеет показать **свою** заявку по коду со статусом и ответом партии.
Показать **чужие** предложения нельзя: API публично их не отдаёт, только
организатору в кабинете. Это правильно — анкета анонимная.

Чтобы сделать витрину «что уже предложили», нужен новый адрес на стороне
сервера. Запрос разработчику готов: `ЗАПРОС-РАЗРАБОТЧИКУ.md` — перешли его,
и я подключу витрину, когда адрес появится.

### Важно про заметки в кабинете

Ответ партии на сайте берётся из **последней заметки в истории заявки**.
Отдельного поля «публичный ответ» у API нет, поэтому всё, что написано
в заметке, увидит заявитель по своему коду.

Служебные пометки («проверить», «дубль», «это от Айгуль») туда писать
нельзя — пиши только то, что можно показать.

# Запрос: публичный список одобренных предложений

Привет! Подключили сайт школьных выборов (vote4musya.vercel.app) к анкете
«Предложения по улучшению школы» — заявки уходят и приходят в кабинет,
всё работает, спасибо.

Не хватает одного: показать на сайте, **что уже предложили другие и что
ответила партия**. Сейчас `/api/forms/track/{код}` отдаёт только свою
заявку по своему коду, а публичного списка нет.

## Что нужно

```
GET /api/forms/public/{formId}/submissions
```

Возвращает **только те заявки, которые организатор явно пометил как
публичные** в кабинете — галочка на самой заявке, по умолчанию выключена.

```json
{
  "success": true,
  "submissions": [
    {
      "code": "T7L97QJLPR",
      "createdAt": { "_seconds": 1789931630 },
      "status": "in_progress",
      "statusLabel": "Взяли в работу",
      "data": {
        "field_1789541693809": "В столовой нет вегетарианского варианта"
      },
      "reply": {
        "text": "Обсудили на встрече партии. Берём в работу с понедельника.",
        "at": { "_seconds": 1790018030 }
      }
    }
  ]
}
```

## Что важно

1. **Только помеченные заявки.** Анкета анонимная, люди писали не для
   публикации. Поэтому не «все, кроме скрытых», а «только явно открытые» —
   организатор решает про каждую.

2. **Никаких персональных полей.** Если в анкете есть имя или контакт —
   не отдавать их в этом ответе, даже когда заявка помечена публичной.

3. **`reply`** — ответ организации. Сейчас он лежит в `history[].note`,
   и брать последнюю заметку неудобно: в истории бывают служебные пометки,
   не предназначенные заявителю. Отдельное поле «ответ, который видно
   публично» было бы надёжнее.

4. Пагинация не нужна — предложений будут десятки, не тысячи. Если проще,
   отдавайте последние 50.

5. CORS с `https://vote4musya.vercel.app` уже работает на других адресах,
   на этом тоже пусть будет.

## Если так нельзя

Достаточно даже счётчика:

```
GET /api/forms/public/{formId}/stats
→ { "success": true, "total": 47, "resolved": 12 }
```

Без текстов, просто цифры — уже даст понять, что предложения реально идут.
